# Installation

[SEEK ](https://seek4science.org/about_us.html)(otherwise known as FAIRDOM-SEEK) is developed and maintained by the FAIRDOM-SEEK group, based out of the EU. NExtSEEK is a wrapper around SEEK, developed and maintained here at MIT, that adds more advanced features to the SEEK system.

Installation of NExtSEEK requires having a working installation of SEEK. Instructions for the installation of both are found on the following pages.
