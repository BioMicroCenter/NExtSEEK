# Admin Pages

### [Admin Page](https://nextseek.mit.edu/admin/)

This is the built in standard mezzanine admin page associated with the NExtSEEK software suite.&#x20;

### [Revise Sample Attributes](https://nextseek.mit.edu/seek/samples/attributes/)

This page allows users to add/remove/edit attributes of Sample Types. This feature is only available on NExtSEEK, as SEEK does not allow for attribute editing. This is very useful when we are working with a new group, and they collect (and want us to include) a new field of a Sample Type that already exists.&#x20;

### [Revise Clade Association](https://nextseek.mit.edu/seek/admin/clades/)

This displays a set of internal databases table specific to NExtSEEK. For more information on Sample Clades, [head here](/mit-data-management-analysis-core/using-seek-and-nextseek.md#clades). This page contains interactive tables that allow setting clade color, and assigning new sample types clades.

### [Admin Sample Retrieval](https://nextseek.mit.edu/seek/admin/retrieve/)

This is the same as the sample retrieval page, but just for Admins, who have access to all assets across all projects. The standard sample retrieval page is slightly slower as the retrieval confirms that you have access to the samples that you are trying to download
