# `NessieAI/docker/cc-runtime/`

## What this is

The Container-CC agent image context. It builds `dmac-assistant:poc`, the image each CC turn runs as
an ephemeral sibling container: a pinned Claude Code CLI on node 22, a uv-managed Python, the baked
`nextseek` plugin, and the agent's own instructions. Compose service `cc-agent` is a build target
only and never runs.

## Surface

| Path | What it is |
|---|---|
| `Dockerfile` | the image build; contains blocks that `NessieAI/build_tools/gen_op_surfaces/` regenerates |
| `build_context/plugins/nextseek/` | the plugin: `plugin.json`, `commands/`, `skills/`, `hooks/`, the `nextseek-*` shims and their helpers in `bin/`, and `context/` (`ops.json`, `read_safe_endpoints.json`, `MANIFEST.md`) |
| `build_context/docs/` | docs baked into the image |
| `container/` | `CLAUDE.md` (what the agent is told; edit only outside its marked blocks), `entrypoint.sh`, `runner_ns.py` |
| `docs/nextseek/` | the ingested NExtSEEK docs, generated by `NessieAI/build_tools/ingest_nextseek_docs/`; do not hand-edit |
| `tools/e2e/` | `judge_runner.py`, the in-image entry for the e2e transcript judge |
| `tests/unit/` | unit tests for the batch-upload shims; `pyproject.toml` and `uv.lock` are this folder's own uv project |
| `PORT-EVIDENCE.json` | the record of the port from the source repo, pinned by `NessieAI/tests/cc/test_step7_cc_runtime_port.py` |

Image-baked content (`docs/`, `container/`) is excluded from the doc checks in `ci/docs_map.py`.
The plugin's `ops.json` is generated from `NessieAI/cc/op_registry/`; add ops only through `/add-cc-op`.

## Running and testing

```bash
./startup.sh rebuild --component cc-agent
```

(`DEPLOYMENT.md` §3.2.) The cc-runtime unit lane and the plugin `bin/` dispatch lane are rows in
`NessieAI/tests/README.md`. The image, digest and compose guards are in `NessieAI/tests/cc/`.

## Depends on / depended on by

Gets the BAML judge client from `NessieAI/dmac_assistant/baml_src/` and the chat_nextseek context
files from `NessieAI/chat_nextseek/` through compose named contexts. `NessieAI/cc/` spawns
containers from it. Parent doc: `NessieAI/docker/README.md`.
