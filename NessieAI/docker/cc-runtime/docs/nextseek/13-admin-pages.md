# Admin pages

These pages are for administrators. You need an administrator account to see them: the Admin section of the left menu only shows for administrators.

| Page | Path | What it does |
|---|---|---|
| Admin Panel | `/admin/` | The standard Mezzanine admin site that comes with NExtSEEK |
| Sample Attributes | `/seek/samples/attributes/` | Add, remove and edit the attributes of a sample type. SEEK itself does not allow this. It is useful when a new group collects a field that an existing sample type does not have yet |
| Clades | `/seek/admin/clades/` | Interactive tables for setting each clade's color and for assigning sample types to clades. See [Sample types](sample-types.md#the-four-clades) |
| Internal Assays | `/seek/admin/internal_assays/` | Connect the assays registered in SEEK to NExtSEEK's internal assays, the general procedures listed in the [Assays](assays.md) catalog |
