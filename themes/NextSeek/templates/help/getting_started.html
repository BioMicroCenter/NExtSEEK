{% trans "What is NExtSEEK?" %}

{% blocktrans trimmed %} NExtSEEK extends the SEEK platform with discrete, mutable sample types and a graph-style assay model. Samples are nodes; assays connect them. The point is to capture enough structured metadata that other researchers (and you, six months from now) can actually reuse the data. {% endblocktrans %}

{% trans "Uploading samples" %}

  1. {% blocktrans trimmed %}Go to Data Entry → Assay Sheet Upload in the sidebar.{% endblocktrans %}
  2. {% blocktrans trimmed %}Download a sample Excel template from the upload dialog if you don't already have one.{% endblocktrans %}
  3. {% blocktrans trimmed %}Fill in your sample rows. Only the first worksheet is processed.{% endblocktrans %}
  4. {% blocktrans trimmed %}Upload. The batch system stages the parse, validates against the schema, then commits.{% endblocktrans %}

{% trans "Searching by UID or text" %}

{% blocktrans trimmed %} By UID: use the Search by UID… input in the sidebar's Quick Access section. Enter a sample UID and hit Enter — you'll land directly on its sample-tree view. {% endblocktrans %}

{% blocktrans trimmed %} By text or filters: use Data Query → Sample Search in the sidebar. You can filter by project, sample type, date, and any indexed attribute. {% endblocktrans %}

{% trans "Using Nessie" %}

{% blocktrans trimmed %} Nessie is the NExtSEEK assistant. You can ask plain-language questions about your data, schema, or workflows. {% endblocktrans %}

{% blocktrans trimmed %} The fastest way in: type your question into the Ask Nessie… input in the sidebar. Press Enter and you'll land in the chat with your question already typed — click send to ask. You can also open the full chat directly via the Talk to Nessie link on the home dashboard. {% endblocktrans %}

{% trans "Common workflows" %}

{% trans "Get a sample's full lineage" %}

  1. {% trans "Search by UID in Quick Access." %}
  2. {% blocktrans trimmed %}You'll arrive at the sample-tree view, which shows all parent and child samples + linked assays.{% endblocktrans %}

{% trans "Pull a project's samples into Excel" %}

  1. {% blocktrans trimmed %}Go to Projects in the sidebar.{% endblocktrans %}
  2. {% blocktrans trimmed %}Open the project page → Export samples.{% endblocktrans %}

{% trans "Publish data externally" %}

  1. {% trans "Open the project page." %}
  2. {% blocktrans trimmed %}Use Publish to push to GEO / SRA / PRIDE / etc. via SEEK's integrations.{% endblocktrans %}
